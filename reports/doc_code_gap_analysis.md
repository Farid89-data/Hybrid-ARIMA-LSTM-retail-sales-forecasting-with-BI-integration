## 5. The 5 most important items to fix first

1. **A-4-39, EXPERIMENT_LOG.csv malformed rows.** Three hand-edited rows shift every column in pandas, so when lane E runs the cost table, the accuracy-cost figures and RQ3 will come out silently empty. Fix the quoting before lane E starts.
2. **A-3-175 / A-4-41, "experiments run one at a time".** This is false under D-026/D-027 (concurrent run, parallel lanes, thread changes, suspension not subtracted), and it underpins the RQ3 cost comparison. Rewrite and disclose it in Limitations.
3. **A-3-193 / A-3-196 / A-3-197 / A-3-202 / A-4-42 / A-E-1-2, tests.** The text says 40 and "All tests pass", but there are 47 tests, the last recorded run had 40, and the results table has 36 rows. Re-run pytest with junit and regenerate the table after lane E.
4. **A-F-8, dashboard MASE.** The dashboard exports neural models at seed 1 only, so "MASE (store average)" will not equal the five-seed MASE in the report tables. An examiner comparing the two will see different numbers.
5. **A-I-6, "nine executed notebooks".** make_notebooks.py is not in any run_parallel lane, so the folder will still be missing when the pipeline ends unless it is run by hand.
